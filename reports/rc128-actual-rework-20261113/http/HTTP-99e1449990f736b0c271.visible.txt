现象
Atlas A3 上，直方图/分箱族算子（torch.bucketize / torch.bincount / torch.histc）出现三档崩溃级失败：
案例
算子与条件
失败形态
bk_right_true
torch.bucketize(..., right=True)
SIGSEGV（exit=-11）
，错误串：
rtGetDevMsg execution failed, the context is a null pointer.
bc_weights_f64
torch.bincount(weights=...)
（f64 权重）
exit=1
FuncError
（error_message_manage.cc:76）
hc_range_drops
torch.histc(...)
（range 参数含边界丢弃场景）
exit=1
FuncError
（同上）
其中 bucketize 的 SIGSEGV 不是普通的 Python 异常——
context is a null pointer
表明
设备上下文被打穿
，属于崩溃级缺陷。同批对照算子（其余 binning 案例及 cat/copy 全案）在 A3 上全部通过，失败面精确锁定。
310P3 同族值面异常（对照参考）
：searchsorted int32 序列 × int64 values 组合返回值与 CPU 不一致（同 dtype exact 判比下 DIVERGE）——直方图族的跨芯行为均不干净。
版本环境
CANN 9.2.1（社区版），Atlas A3，openEuler 容器
torch 2.11.0 + torch_npu 2.11.0rc1（pip）
每案独立子进程隔离，CPU 同码对照；crashes 计入探针指纹
最小复现
import
torch, torch_npu
torch.npu.set_device(
0
)
dev = torch.device(
"npu:0"
)
x = torch.rand(
1000
, device=dev) *
10
b = torch.linspace(
0
,
10
,
11
, device=dev)
idx = torch.bucketize(x, b, right=
True
)
# A3: SIGSEGV / context is a null pointer
bincount f64 weights 与 histc range 场景同族复现 FuncError（探针日志含完整案名与退出码）。
期望 vs 实际
期望
：bucketize/bincount/histc 为 torch 核心算子，CPU 侧全部正常；NPU 侧即便有实现缺口也应干净报
RuntimeError
。
实际
：bucketize 直接 SIGSEGV 打穿设备上下文，bincount/histc 报不透明的 FuncError（错误串指向 error_message_manage 内部而非用户可理解的规格说明）。
凭证
独立子进程取证、退出码与错误串逐字在档（t319_binning_953.log）；同批 cat/copy 案全净（排除环境噪声）。
