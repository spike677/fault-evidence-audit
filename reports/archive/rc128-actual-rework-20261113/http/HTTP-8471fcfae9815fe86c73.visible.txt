描述
本次提交针对社区 issue #6788/#6789（共性问题）修复了 all_gather_matmul 与 all_gather_matmul_v2 两个算子的中英文 API 文档及 README 共 5 个文件：为 aclnnAllGatherMatmul 错误码表补齐"x1的k轴为0"的 161002 场景并修正 rowspan 与描述行数不匹配问题；将 aclnnAllGatherMatmulV2 错误码表由 1 行精简补齐为 3 行（数据类型和 shape 维度/尺寸、streamMode/commMode 取值、format 约束及量化/fp16/bf16 场景下 scale 与 amaxOut 空指针约束），rowspan 同步对齐；经源码裁决 quantScale 以 tiling 层端到端口径为准，维持"仅支持空指针"表述不变；并将"all mesh组网"统一改为"Full Mesh（全互连）组网"（英文 full mesh networking），与代码侧 full_mesh 实现命名一致。
