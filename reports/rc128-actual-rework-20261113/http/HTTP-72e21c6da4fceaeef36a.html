描述

InstanceNorm（Ascend950 arch35）空归约兜底模板 InstanceNormReduceEmpty（R==0 且 N*C>0 时进入，tilingKey=50000）原先将 mean/variance 双双填 NaN。该填充值与以下三方均不一致：

参照 空归约填充约定
PyTorch CUDA welford（torch 2.7.0+cu126 / 2.14.1+cu130 双版本实测，A100） save_mean=0 / save_invstd=NaN
仓内同语义空模板 add_layer_norm_regbase_reduce_empty.h（其文件注释即写明"mean=[A,1] 填 0、rstd=[A,1] 填 NaN"） mean=0 / rstd=NaN
aclnnBatchNorm L2 空进填充（ProcessEmptyTensorWithValue(saveMean, 0) / saveInvstd, NaN)） saveMean=0 / saveInvstd=NaN

本改动将空归约时 mean 填充值改为 0（variance 保持 NaN），并把实现方式对齐 add_layer_norm_regbase_reduce_empty：同一 buffer 分两段填充 0 和 NaN 后循环搬出（原先共用一个 NaN tensor 拷给两路输出）。

实际影响面有限（torch 对外不暴露 instance_norm 统计量、InstanceNormGrad 空模板自身填 0 不消费统计量输出），但以 torch 逐实例统计量为 golden 的精度对比会出现 NaN vs 0 的假红；且本改动消除 CANN 生态内同一"空归约"语义下两种填充约定的分叉。

验证

  • 环境：Ascend950PR + CANN 9.3.0，master (63513a9e2) 构建 --ops=instance_norm --soc=ascend950 --pkg，以自定义算子包（ASCEND_CUSTOM_OPP_PATH）覆盖内置二进制
  • 空进非空出用例 x=(2,4,0,3) fp32/NCHW：mean=0、variance=NaN，与更新后 golden 精确匹配（ttk kernel 模式 PASS）
  • 正常 shape 对照用例无回归（PASS）
  • 反汇编 diff 确认语义变化完全限定在 InstanceNorm_..._50000（ReduceEmpty）符号内（新增第二组 Duplicate 填充与 NaN 常量构造、buffer 移位 #2→#3）
  • 依赖检查：InstanceNormGrad 空模板 instance_norm_grad_empty_load.h 自身填 0、不读取 mean/variance 统计量，无下游影响
  • 无测试锁定旧行为（UT 仅校验 tiling 数据切分，无填充值断言）

变更摘要

本改动修复 InstanceNorm（arch35）空归约兜底模板 InstanceNormReduceEmpty（R==0 且 N*C>0，tilingKey=50000）的填充约定：原先 mean 与 variance 均填 NaN，现改为 mean 填 0、variance 保持 NaN，与 PyTorch CUDA welford 空归约结果（save_mean=0 / save_invstd=NaN）、仓内 add_layer_norm_regbase_reduce_empty.h 以及 aclnnBatchNorm 空进填充约定对齐，消除 CANN 生态内同一“空归约”语义下的填充值分叉。

主要改动

  • mean 填充值改为 0：Process() 中先以 Duplicate 将整段 buffer 前半填 static_cast<T_MEAN>(0)，后半填 QuietNaN()，使空归约输出的 mean 为 0、variance 为 NaN。
  • 单 buffer 双段填充替代共用 NaN tensor：队列由 outNanQueue_ 重命名并改为 outQueue_，InitBuffer 容量由 perCorePerLoopElements_ 扩为 NUM_TWO * perCorePerLoopElements_ * sizeof(T_MEAN)，新增常量 NUM_TWO = 2。
  • 搬出逻辑按段索引取地址：CopyOut 参数由 runningMeanTypeNanLocal 改为 fillLocal，meanGm_ 搬出 fillLocal，varianceGm_ 搬出 fillLocal[perCorePerLoopElements_]，实现同一个 buffer 分两段循环搬出。
  • 文件头注释更新：instance_norm_reduce_empty.h 的 \brief 补充说明空张量兜底 kernel 的填充约定及其与 add_layer_norm_regbase_reduce_empty、PyTorch CUDA welford 的一致性依据。
