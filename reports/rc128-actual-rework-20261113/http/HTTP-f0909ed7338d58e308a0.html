变更摘要

本 PR 为 allgather mesh 1d 的 AIV kernel 增加调试日志能力：在 aiv_all_gather_mesh_1d.h 与 aiv_all_gather_mesh_1d_write.h 两个 kernel 实现中插入带编号的 AIV_INFO 打印，并在入口、循环与退出等关键节点按 blockIdx_ == 0 条件只由首个 block 输出概要信息；同时按 PR 标题所述开启 ASCENDC_DUMP。改动整体聚焦于可观测性，不改变数据搬运与同步流程本身。

主要改动

  • 读语义 kernel 全流程埋点: 在 aiv_all_gather_mesh_1d.h 中新增 AG1D0000～AG1D1090 系列打印，覆盖 InitCoreInfo、Run、RunCtrlCore 中的 CpGM2GM、Record、WaitFlag、PipeBarrier、SyncAll 以及 Process／BarrierAll 各阶段完成点。
  • 写语义 kernel 全流程埋点: 在 aiv_all_gather_mesh_1d_write.h 中新增 AGW1D0000～AGW1D0061 系列打印，覆盖 READY／CONSUMED／READ_DONE 标志的发布与等待、SendCachedPiece／SendPiece 的 DataCopyGM2UB、DataCopyUB2GM 与 CpGM2GM 搬运，以及自拷贝路径和核间同步点。
  • 单核门控的概要日志: 入口参数（rank_、rankSize_、numBlocks_、len、tag_、sliceId、pingpong）与 AivAllGatherV2Mesh1DSuperKernel 的循环进度、退出信息仅在 op.blockIdx_ == 0 时打印，避免多核重复输出。
  • 同步状态可追踪: 每条日志同时输出 blockIdx_、targetRank／rank、flag 偏移量与 curTag_、搬运计数，便于按核与流水阶段定位多卡同步与数据搬运的执行顺序。
  • 开启 dump 配置: 按 PR 标题所述开启 ASCENDC_DUMP，用于配合上述调试打印进行运行时信息采集。
