# 状态兼容边界

0.1.21的有效规则是原V4和原42。历史运行可能应用过V4解释覆盖、修订42、crosswalk或额外执行方法；这些状态不自动等同于本版原始规则。

- 本仓不发布历史state、原请求/响应或旧验收结果。
- 旧profile应显式拒绝或提示重新建立原始规则run，不能将旧ACCEPTED重标为新profile有效。
- 用户现场仍需恢复旧任务时，先停止写入并作SQLite一致备份；有WAL时不能只复制主文件。保留原版本、Policy、预算、请求hash和响应，按旧版本只读核对。
- 不替换数据库内绝对路径字符串、不回写旧响应、不伪造人工ACCEPT。跨目录恢复或规则变更后重新执行，明确关联旧run但不复用结论。
- 原输入不完整、来源未获取、语义判断未做、设备未运行分别记录，不用mock或协议通过替代真实验证。
