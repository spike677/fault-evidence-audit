Background（背景信息）
scripts/fusion_config/fusion_pass/config/support_fusion_pass.json
维护各 SoC 版本开启的图融合 pass 列表，当前仅有
3510
、
5102
两个条目。9201 / 9202（DAV_9201 / DAV_9202）平台缺少图融合 pass 配置，图融合能力无法在该平台生效。
Origin（信息来源）
内部需求：DAV_9201/9202 平台使能。算子侧已有 DAV_9201 架构使能推进（如 #522 broadcast 模板），本配置为图融合配套同步项。
Benefit / Necessity （价值/作用）
9201 / 9202 平台获得与 3510 一致的 139 个图融合 pass（MatMul 系列、RMSNorm/LayerNorm 系列、Attention 量化系列、AllGather/ReduceScatter 通信融合系列等）
纯配置新增，3510 / 5102 现有条目行为不变
