变更摘要
本 PR 针对
mixed_quant_sparse_flash_mla
算子的
MqsmlaKernel
做两处修正：一是调整空行（无有效
n_end
的物理行）输出初始化的遍历方式，使其不再依赖库元数据调度出的 FA 核心，从而覆盖未被调度的 padding 尾部行；二是在输入校验
_validate_inputs
中新增布局组合约束，要求非 PA KV 场景下
layout_q
与
layout_kv
一致。
主要改动
空行初始化与调度解耦
: 将空行处理循环由按
row_count
行序、经
self._m_idx(m_seq)
映射，改为按
blocks = self._ws.shape[0] // WS_BYTES_PER_CORE
步长在
self._ori_idx.shape[0]
物理行范围内遍历，使
O
/LSE 行初始化不再取决于 FA/FD 的核心归属，可覆盖全 padding/全空 batch 及未调度的 padding 尾部。
先排空流水再写空行输出
: 保留并更新注释，明确需先
drain
流水线再执行
finalize_empty
，因为后者复用同一输出缓冲区，避免与待处理 PV 相互干扰。
新增布局一致性校验
: 在
_validate_inputs
中增加判断，当
layout_kv != "PA_BBND"
且
layout_q != layout_kv
时抛出
ValueError
，明确非 PA KV 只接受
layout_q
与
layout_kv
相同的组合。
