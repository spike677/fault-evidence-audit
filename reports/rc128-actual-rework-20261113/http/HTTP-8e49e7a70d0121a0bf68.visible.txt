问题描述
Qwen-Image-2.1 推理指南需要区分 true CFG 与 CFG 并行，避免不传负向提示词时使用 2 路 CFG 造成冗余计算；同时补齐镜像部署、机型与量化说明。
预期修改
基础请求不启用 true CFG，提供单卡及 8 卡 Ulysses 配置，简述启用 true CFG 的条件。
使用支持模型的官方镜像部署，补充 Atlas 800I A2 推理服务器与 Atlas 800I A3 超节点服务器。
修正编辑请求省略 size 时使用第一张参考图像的说明。
使用 FLASH_ATTN 后端调用 MindIE-SD 注意力算子，补充 INT8、MXFP8 在线量化完整命令及范围说明。
保留必要使用说明，删除优化点罗列。
验收方式
核对参数与接口含义，通过改动文件的 pre-commit、Markdown、Bash/JSON 和 diff 检查；运行验证范围在 PR 中单独注明。
