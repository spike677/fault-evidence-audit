问题/功能描述

修复了并行线性层中偏置（bias）返回逻辑的错误。原代码在 skip_bias_add 标志为 True 时，错误地将偏置在线性计算中直接添加，导致在需要延迟偏置添加的场景下，计算逻辑与预期不符，可能影响模型训练的正确性。

修改方案描述

调整了 MindSpeedTELayerNormColumnParallelLinear 类 forward 方法中偏置的处理逻辑。核心修改是：在调用线性计算函数时，根据 skip_bias_add 标志决定是否传入偏置；在函数返回前，根据 te_return_bias 标志决定是否返回偏置。这确保了当 skip_bias_add 为 True 时，偏置不会在线性计算中被添加，而是作为第二个返回值返回，供后续处理，从而与模块的设计意图保持一致。
