描述
FlashAttn 原三方精度判据为 L0。本 PR 升级为 L2，并整合 GPU FA3 sinks 适配。默认三方路径为：
NPU FlashAttn 算子输出、GPU FA3 标杆、CPU FP32 golden
。
默认 CPU golden 沿用 FA3 分支的独立 dense FP32 实现：完整 QK、softmax、PV 和 LSE 使用 FP32，不因
--compare cross_check
自动升为 FP64。
默认通过 TTK 原生三方比较器及 GPU XPU 服务执行 FA3，支持布局/分页转换、sinks 后处理和 LSE。缺少 GPU 服务时明确失败，不回退到 NPU 小算子。
三方采用 TTK L2 预设：mare/mere/rmse 比值上限 2/1.2/1.2；移除旧 L0 数字覆盖，小值域与 NaN/Inf 规则由 TTK 处理。
显式设置
FLASH_ATTN_CROSS_CHECK_BACKEND=npu
可使用本地 NPU 小算子备选方案，该独立路径保留原有 CPU FP64 参考。
reference_mode=mixed/fp64
仅为显式选项，默认 FA3 路径使用
fp32
。
测试资产可在没有 TTK/NPU 包的环境导入，兼容 GPU 远程服务和离线工具加载。
新增
offline_compare.py
：读取完整输入 PT 和已有 NPU/GPU 输出 PT，在 CPU 上生成 FP32 golden 并离线比较；不执行 NPU/GPU 算子。当前支持非分页布局、mask_mode 0/3/4 和 sinks。报告包含两侧原始 MARE/MERE/RMSE、比值、分母下限及特殊分支，便于定位
mare=1.0
。
FA3 代码、工具、用例和运行文档来自
PerrySkywalker/feat/flash_attn_ttk_fa3_sinks
，整合截至
84a5235da
，保留其原提交历史。FA3 计算模块位于
impl/fa3.py
。
关联的Issue
无。
测试
既有三方实现 1,266 项回归全部通过：覆盖 FA3 CPU stand-in 数值/布局/sinks/分页/维度转换、默认与显式标杆选择、默认 CPU FP32、备选参考模式和统一 L2 参数解析。
新增离线工具 55 项测试通过，其中 36 项与 TTK 比较器直接核对。命令行测试禁止导入 TTK、torch_npu、FA3 和算子包，验证纯 CPU 运行；同时覆盖完整输入包、mask/sinks、输出选择、CPU golden 保存和回放。
不设置标杆选择变量的实际 TTK 调用，日志确认 attention golden 和 LSE golden 均为
float32
；缺少 GPU 服务时返回预期的
GOLDEN_FAILURE
，未调用 NPU 小算子回退。
NPU 小算子备选方案在整合阶段完成 Ascend950DT 实卡 E2E 4/4 PASS，覆盖 FP16/BF16 × 无掩码/因果掩码，每例 attention 输出和 LSE 均通过 L2。
重新生成 40 条 GPU smoke 和 474 条 FA3 scope CSV，与入库资产逐字节一致。
Ruff 检查、格式检查及
git diff --check
通过。
验证边界：当前无可用 CUDA/FA3 环境，真实 GPU FA3 及跨机 GPU/NPU 精度尚未验证，CPU stand-in 测试不代表真实 CUDA 执行通过。NPU 备选路径的实卡验证复用了服务器 20261107 现有算子包，未从当前 master 重新编译内核；该备选路径要求 PyTorch/torch_npu 支持
torch.mm(..., out_dtype=torch.float32)
。
文档更新
更新 README.md 和 README_FA3.md，明确默认 NPU/GPU FA3/CPU FP32 路径、L2 判据、依赖、两端部署及验证边界。带入 FA3、TND 16K/batch 13、scope、未来维度及 GPU smoke 用例和生成工具。
补充离线比较工具的 PT 格式、命令行、原始误差解释、非分页范围和退出码说明。
