变更摘要

该 PR 旨在修复 RadixTopK 算子中因多流水/多核同步缺失而导致的同步错误，核心手段是在关键计算路径上补充显式同步屏障（SyncAll()、SToVSync()、MTE3ToSSync()、VToSSync()），确保各流水阶段数据就绪后再执行后续运算，并将部分工具函数调整位置以使其能调用同步接口。

主要改动

  • SubProcess 提前退出后补充同步：在 radix_top_k_ub.h 的 SubProcess 中，Update(roundId) 命中 topk 提前 break 的分支之后新增 SyncAll()，确保退出轮次前各核/流水状态一致。
  • HandleLastRoundBoundary 运算前增加同步：在 radix_top_k_ub.h 的 HandleLastRoundBoundary 中，执行 Sub 向量减法前新增 SToVSync()，避免向量流水读到的直方图数据未就绪。
  • TileTopK 获取 topk 后增加同步：在 radix_top_k_ub.h 的 TileTopK 中，CopyInCoreTopK(tmpLocal) 返回偏移量之后新增 SyncAll()，保证核间 topk 结果同步完成后再计算 batchIndexOffset 等后续偏移。
  • CreateVecIndexPerf 增加流水同步并调整工具函数位置：在 radix_top_k_utils.h 中，CreateVecIndexPerf 生成索引前新增 MTE3ToSSync() 与 VToSSync() 同步；同时将 CopyData、CreateVecIndexDataByAdds、CreateVecIndexData、CreateVecIndexPerf 等工具函数整体移动到同步宏定义之后，使其能够引用上述同步接口。
