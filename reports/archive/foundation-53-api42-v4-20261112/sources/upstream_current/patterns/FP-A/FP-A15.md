# FP-A15 inf/nan 特殊值行为差异

> [← 库索引](../../README.md) ｜ [变更记录](../../CHANGELOG.md) ｜ 类别：精度 ｜ 风险：高（S3×O2=6） ｜ 状态：活跃

- **适用**：仓 All ｜ 侧别 Kernel ｜ 载体 Kernel源码 ｜ 触发 isnan|IsNan|NAN|INFINITY|rsqrt|sqrt|E\[x²\] ｜ 默认启用 true

- **子型**：① **特殊值输入**（nan/inf 进入后比较分支、传播、clamp 行为与标杆不一致——原主干）；② **定义域越界产出**（输入全为有限合法值，但中间表达式因舍入/抵消落到数学定义域之外，产出 nan/inf——v2.18 增补）。
- **故障机理**：① nan 比较分支结果（如 nan 与阈值比较的判断走向）、inf 传播与标杆不一致；`float == NaN` 恒假类分支写错。② **正常输入算出非法中间值**：典型是「先算平方和再减均值平方」这类数学等价但数值不等价的写法——`E[x²]-E[x]²` 在方差极小时，两个大数相减发生**灾难性抵消**，舍入误差可让结果落到 `-ε`（负方差），再经 `sqrt`/`rsqrt` 变成 **NaN**；同理 `std` 的负数、`log(0)`、`1/x` 除零、`acos` 越界都属于本型。**特征：输入完全合法，缺陷在公式的数值形态，不在输入校验。** ③ **掩码/布尔语义错位（v6.33）**：bool mask 的 `true/false` 语义与资料公式相反（该屏蔽的位置被保留），或用 `-10000`/`-1e4` 等有限大负数代替 `-inf` 做屏蔽——有效位 logits 低于该常量时屏蔽位吃掉全部概率；与 ① 的区别是输入不是 nan/inf，而是**语义方向错了**。
- **触发条件**：① 输入含 nan/inf 或计算过程中产生。② 数值动态范围大、方差/范数接近零、大量零元素、接近 `1e-7` 量级的极小数、`inf - inf` 型中间结果；**提高零元素比例直到旧实现中间方差为负**是最可靠的构造方式。
- **典型表现**：① 特殊值场景结果不一致、nan 用例判断失败。② 输出出现无来源的 nan（追查输入却找不到 nan/inf）、loss 突然变 NaN 且不可复现、同一输入不同 batch 组合下偶发 nan；**关键鉴别点：输入侧查不到 nan/inf，nan 是本地生成的**。
- **源码审查映射点**：① 特殊值处理：inf/nan 传播、比较分支、clamp 对 nan 的行为。② **一切含有减法的「平方和 - 平方的均值」形态**（方差、标准差、RMS、协方差、LayerNorm/IN 类归一化）；`sqrt`/`rsqrt`/`log`/`div` 的**实参是否做过定义域钳制**（`max(x, 0)`、`max(x, eps)`）；归约是「双遍（先均值再偏差）」还是「单遍平方和相减」；是否存在 `rsqrt(0)` 合法路径；`eps` 是加在方差上还是加在 std 上（影响量纲与数值稳定性）。
- **测试拦截建议**：① nan/inf 专项用例矩阵（输入携带/计算产生/输出注入三类来源）。② **定义域探针**：构造使中间结果为负的输入（零元素比例阶梯 0/50%/90%/99%、常数列、极大极小混合、`x` 与 `x+1e-7` 并置）；判据不是「与参考差距小」，而是**「输出有限且定义域内」**——`variance >= 0`、`std >= 0`、`rsqrt` 结果非 inf/nan、`log` 实参 > 0。同时与 CPU 参考的**稳定性**对照（参考实现用双遍或 Welford，不应出现 nan）。③ 修复前后用同一份固化输入 + 固定种子，确认「旧版中间方差为负、新版非负」。
- **实证案例**：**子型①**：ops-nn #5562 threshold_grad_v2_d nan 用例判断失败（PR !9773，kernel isnan 分支未对齐标杆）。**子型②**：ops-math `INTrainingUpdateV2`（PR 修复，现网 25-11）——`E[x²]-E[x]²` 单遍算法在舍入抵消下产生**负方差**并传播为 NaN；修复在 `after_v200()` 路径新增 `max(variance, 0)` 下界钳制。**该修复只钳了被开方的一次**，审查同类算子时须同时确认「钳制点是否覆盖所有 `sqrt/rsqrt` 消费方」。 **2026-11 批次（v6.33 反哺）**：本簇 9 条；代表 ops-nn#7120（ScaledMaskedSoftmax bool mask 极性反转）、#7121（常量 -10000 代替 -inf）、ops-math#4006（大数取模塌成 0）。
