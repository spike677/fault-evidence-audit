变更摘要

本 PR 修复 mc2/allto_allv_quant_grouped_mat_mul 模块中 AlltoAllvQuantGroupedMatMul 及 V2 接口的参数校验错误码区分问题：此前 gmmWeight 非空但维度不为 3 维时，会与空指针情形一并返回 161001（空指针错误），本次改为分别返回 161001 与 161002（参数非法），并通过单元测试固定该行为。

主要改动

  • CheckGmmWeightValid 返回值类型调整：aclnn_allto_allv_quant_grouped_mat_mul.cpp 与 aclnn_allto_allv_quant_grouped_mat_mul_v2.cpp 中的内部校验函数由返回 bool 改为返回 aclnnStatus，空指针返回 ACLNN_ERR_PARAM_NULLPTR（161001），非 3 维返回 ACLNN_ERR_PARAM_INVALID（161002），全部合法返回 ACLNN_SUCCESS。
  • GetWorkspaceSize 入口错误码透传：aclnnAlltoAllvQuantGroupedMatMulGetWorkspaceSize 与 aclnnAlltoAllvQuantGroupedMatMulV2GetWorkspaceSize 改为先保存 gmmWeightCheckRet，再用 CHECK_RET(gmmWeightCheckRet == ACLNN_SUCCESS, gmmWeightCheckRet) 返回真实错误码，不再统一按 ACLNN_ERR_PARAM_NULLPTR 上报。
  • V1 新增维度非法用例：test_aclnn_allto_allv_grouped_mat_mul_nullptr.cpp 新增测试 aclnnAlltoAllvQuantGroupedMatMulGmmWeightWrongDim，构造 2 维 gmmWeight，断言返回 ACLNN_ERR_PARAM_INVALID（161002）。
  • V2 用例断言收紧：test_aclnn_allto_allv_grouped_mat_mul_nullptr_v2.cpp 中 GmmWeightWrongDim 由「允许 161002 或 161001 任一通过」改为严格断言等于 ACLNN_ERR_PARAM_INVALID。
