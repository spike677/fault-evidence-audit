make_graphed_callables
中原始 autograd bridge，使用 CPU replay 替身；
torch.autograd
和 AdamW 均实际执行。没有将该测试描述为真实 NPU capture。
问题
bridge 的 backward 返回
b.detach()
，与 capture 的静态梯度缓冲共享存储。外部 Autograd 可能直接保留这块存储作为叶子的
.grad
。下一次 graph replay 覆盖静态缓冲时，前一微批累计的梯度或调用者保存的输入梯度也被覆盖。
最小例子使用
f(x,w)=x*w
，四个微批 x=1,2,3,4，期望 w.grad=10；原 bridge 的 CPU replay 用例得到 8。另一个用例保留第一次输入的 grad，第二次 replay 后其值被改变。连续两次 AdamW 的累计梯度也与 eager 不同。
建议与验证
将返回给外部 Autograd 的非 None 梯度复制到独立存储：
b.detach().clone()
。保留 None、原参数对象、前向输出及 replay 流程。
随 PR 的三个 CPU bridge 回归在补丁前全部失败、补丁后全部通过；另提供
RUN_NPU_GRAPH_TESTS=1
显式开启的真实 NPU capture 四微批/两次 AdamW 集成用例，本次未运行以免占用其他任务设备。该变更涉及存储所有权，申请 SIG/维护者审查；不以 CPU replay 替身替代 NPU 性能和并发验证。
