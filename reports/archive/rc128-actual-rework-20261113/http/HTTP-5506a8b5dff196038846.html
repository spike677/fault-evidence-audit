现象

aclnnChunkGatedDeltaRule 的两类参数错误返回码都与资料承诺不符：

# 变异 实测第一段 资料承诺 资料位置
1 query = nullptr（其余合法） 161002（ACLNN_ERR_PARAM_INVALID） 161001（ACLNN_ERR_PARAM_NULLPTR） aclnnChunkGatedDeltaRule.md:239-241「query、key、value、beta、initialState、actualSeqLengths、out、finalState存在空指针」
2 非空 + shape 不匹配（key 的 dimK=16 vs query 32） 561103 561002（ACLNN_ERR_INNER_TILING_ERROR） :250-251「传入的 … 的 shape 不匹配」

根因 1：attention/chunk_gated_delta_rule/op_host/op_api/aclnn_chunk_gated_delta_rule.cpp:141 是 CHECK_RET(CheckNotNull(params), ACLNN_ERR_PARAM_INVALID); —— 判空函数本身（:64）逐字段判空是对的，错的是错误码选了 161002（资料要求 161001）。
根因 2：shape 不匹配在 tiling 侧被拒（plog：chunk_gated_delta_rule_tiling.cpp:106 Invalid shapes → kernel_workspace.cpp:95 Kernel GetWorkspace failed errno 561103），冒泡成 561103 而非资料承诺的 561002。

期望

两类错误分别返回资料承诺的码：空指针 → 161001，shape 不匹配 → 561002。同仓同类变异作对照：aclnnFlashAttentionScoreV2 / aclnnSparseFlashAttention / aclnnFlashAttentionScoreGradV4 的空指针变异都返回 161001，说明本仓口径本应是 161001。

与同接口既有单的区别：ops-transformer#7038（closed）是同算子 UT 失败聚合、#7036（closed）是 CI 环境 socName 为空导致 561103。本条是发布件上两类参数错误的返回码与资料承诺不符（空指针 161002≠161001、shape 不匹配 561103≠561002），请勿合并。

交叉验证（双版本 + 独立复跑）：

  • 提交方（我）：A5 + 9.3.0.B020，query=nullptr → 第一段 161002，同进程合法基线 rc1=0、ws=16777728；
  • 交叉方（独立探针）：9.3.0.B020 上 base=0、null_q=161002、bad_dtype=161002 —— 与我的结果一致；
  • 版本对照：同一探针在 9.2.0-beta.2 上也是 base=0、null_q=161002 ⇒ 该行为与版本无关，不是 9.2→9.3 的版本差异导致的读数；
    交叉方二（verifier，device=1，9.3.0.B020，自写探针，按调用位顺序 + gOptional=FLOAT）：基线 rc1=0（ws=35242496），query=nullptr → rc1=161002（ws=0），与提交方及交叉方一一致；三方在 9.2/9.3 上均为 161002 ⇒ 与版本无关。

与 Nsa 的区别（避免混淆）：aclnnNsaCompressAttention 是版本差异（9.2=561103 → 9.3=161001，已修，不再提）；本条 kda 不是版本差异（9.2 与 9.3 都是 161002）。

  • 因此本条结论（空指针应返回 161001、实测 161002）在 9.3.0.B020 上稳定成立。

合法基线（供维护者复现）：q/k={64,4,32} bf16、v/out={64,8,32} bf16、beta={64,8} bf16、initialState={2,8,32,32} bf16、g={64,8} fp32、actualSeqLengths={2} int32、scale=1.0（batch=2, seq=32, headK=4, headV=8, dimK=32, dimV=32）→ rc=(0,0)、ws=16777728、out 与 finalState 各写 16384/16384。

// aclnnChunkGatedDeltaRule：两类参数错误的返回码与资料不符（空指针 161002≠161001、shape 不匹配 561103≠561002）
#include <cstdio>
#include <cstdint>
#include <vector>
#include "acl/acl.h"
#include "aclnnop/aclnn_chunk_gated_delta_rule.h"
static void* Dev(int64_t b) { void* p = nullptr; aclrtMalloc(&p, b, ACL_MEM_MALLOC_HUGE_FIRST); if (p) aclrtMemset(p, b, 0, b); return p; }
static aclTensor* T(std::vector<int64_t> d, aclDataType dt, void* p) {
    std::vector<int64_t> s(d.size(), 1);
    for (int i = static_cast<int>(d.size()) - 2; i >= 0; --i) s[i] = s[i + 1] * d[i + 1];
    return aclCreateTensor(d.data(), d.size(), dt, s.data(), 0, ACL_FORMAT_ND, d.data(), d.size(), p);
}
// 合法基线：batch=2 seq=32 headK=4 headV=8 dimK=32 dimV=32
static void Run(const char* tag, bool nullQuery, bool badShape) {
    int64_t B = 2, S = 32, HK = 4, HV = 8, DK = 32, DV = 32;
    const int64_t dk = badShape ? 16 : DK;   // 证据 2：key 的 dimK 与 query 不一致
    aclTensor* q = T({B * S, HK, DK}, ACL_BF16, Dev(B * S * HK * DK * 2));
    aclTensor* k = T({B * S, HK, dk}, ACL_BF16, Dev(B * S * HK * dk * 2));
    aclTensor* v = T({B * S, HV, DV}, ACL_BF16, Dev(B * S * HV * DV * 2));
    aclTensor* beta = T({B * S, HV}, ACL_BF16, Dev(B * S * HV * 2));
    aclTensor* init = T({B, HV, DK, DV}, ACL_BF16, Dev(B * HV * DK * DV * 2));
    aclTensor* g = T({B * S, HV}, ACL_FLOAT, Dev(B * S * HV * 4));
    aclTensor* seq = T({B}, ACL_INT32, Dev(B * 4));
    aclTensor* out = T({B * S, HV, DV}, ACL_BF16, Dev(B * S * HV * DV * 2));
    aclTensor* fin = T({B, HV, DK, DV}, ACL_BF16, Dev(B * HV * DK * DV * 2));
    uint64_t ws = 0; aclOpExecutor* ex = nullptr;
    const aclTensor* qArg = nullQuery ? nullptr : q;
    int rc1 = int(aclnnChunkGatedDeltaRuleGetWorkspaceSize(qArg, k, v, beta, init, seq, g, 1.0f, out, fin, &ws, &ex));
    int rc2 = -1;
    if (rc1 == 0) { void* w = ws ? Dev(int64_t(ws)) : nullptr; rc2 = int(aclnnChunkGatedDeltaRule(w, ws, ex, 0)); aclFree(w); }
    printf("[%s] rc1=%d rc2=%d ws=%llu\n", tag, rc1, rc2, (unsigned long long)ws);
    aclDestroyTensor(q); aclDestroyTensor(k); aclDestroyTensor(v); aclDestroyTensor(beta);
    aclDestroyTensor(init); aclDestroyTensor(g); aclDestroyTensor(seq);
    aclDestroyTensor(out); aclDestroyTensor(fin);
}
int main() {
    aclInit(nullptr); aclrtSetDevice(0);
    Run("对照组 合法基线", false, false);
    Run("证据1 query=nullptr", true, false);
    Run("证据2 key dimK 不匹配", false, true);
    aclrtResetDevice(0); aclFinalize();
    return 0;
}

影响

调用方按资料区分「参数错误（161001/161002）」与「系统内部错误（561xxx）」：现在空指针被报成参数非法、shape 不匹配被报成 tiling/内部错误，上层无法据此决定是修参数还是重试/上报，错误分类与降级策略全部错位；不影响计算结果。

建议

:141 的 CheckNotNull 失败改为返回 ACLNN_ERR_PARAM_NULLPTR（161001）；shape 不匹配在 aclnn 第一段或 tiling 出口映射为 ACLNN_ERR_INNER_TILING_ERROR（561002），与资料 :250-251 对齐，并补两条 UT 固定这两个码。

另：空 seq（seq=0）实测返回 561103，但资料 :101/:111/:121/:131/:143/:156 明写「不支持空Tensor」，空输入报错属预期，本单不把它作为证据。

问题说明

您提供的实测与文档摘录表明，两类错误在第一段接口返回的错误码存在不一致：query=nullptr 返回 161002 而非 161001；key 的 dimK=16、query 的 dimK=32 时返回 561103 而非 561002。这会影响调用方的错误分类；具体返回路径仍需核实。

处理建议

若 CheckNotNull 失败分支确如报告所述，可将其返回码改为 ACLNN_ERR_PARAM_NULLPTR，保留可选输入 g 允许为空的行为。shape 错误需先确认 tiling 失败如何转换为公开返回码，再考虑针对形状不匹配返回 561002，避免将其他内部故障一并映射。建议补充两类错误码回归用例，并保留合法基线；空 Tensor 不纳入本单范围。
