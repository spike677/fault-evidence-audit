Subject: [PATCH] fix(dataloader): honor seed in BaseRandomBatchSampler
 shuffling (#686)

Both fsdp and non-fsdp BaseRandomBatchSampler (and its subclass
BucketBatchSampler) initialized the shuffle generator with self.epoch
only, ignoring self.seed passed via the trainer's training.seed. Sample
order therefore stayed identical across different seeds.

Seed the generator with self.seed + self.epoch, matching the convention
already used elsewhere in this file (VariableVideoBatchSampler,
AESampler, LuminaMetaLenDistSampler).
