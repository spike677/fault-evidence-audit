bitwise_and、bitwise_xor、equal 三个算子的 InferDataType 均为共享直通注册：IMPL_OP(BitwiseAnd/BitwiseXor).InferDataType(InferDataTypeOutputSameAsInput) 直接照抄输入 dtype 到输出，InferDataType4Equal 则无条件 SetOutputDataType(0, DT_BOOL)，三者都不读输入 dtype、不做域检查与跨输入一致性检查。后果是域外 dtype（如 complex128、bool）与「x1 与 x2 dtype 不一致」在 Host 图推断阶段一律返回成功，错误推迟到执行阶段。

本 MR 按同仓 InferDataTypeAddV2 的先例形态（math/add_v2/op_graph/add_v2_graph_infer.cpp）改为自定义校验回调，三处一致：

  1. math/bitwise_and/op_graph/bitwise_and_graph_infer.cpp：新增 IsSupportedIntegerDtype（8 种整型，与 def 注册域一致）与 InferDataType4BitwiseAnd——检查 x1 域内、x1 与 x2 同 dtype，通过后 SetOutputDataType(0, x1DataType)；域外或不等时以 OP_LOGE_FOR_INVALID_DTYPE／OP_LOGE_FOR_INVALID_DTYPES_WITH_REASON 报错并返回 GRAPH_FAILED。原直通注册行删除。
  2. math/bitwise_xor/op_graph/bitwise_xor_graph_infer.cpp：同形态（域检查＋等值检查＋输出设置）。该算子一条修复同时闭合四行 op_issue：域外 dtype、域外被接受、跨输入 dtype 不一致、以及其 relation 写法的同事实双写法。
  3. math/equal/op_graph/equal_graph_infer.cpp：在保留输出为 DT_BOOL 的前提下，补 x1/x2 dtype 等值检查（proto 声明 x2 same dtype as x1），不一致返回 GRAPH_FAILED。

改动范围 3 文件。本 MR 为静态修复，行为验证待上板或 UT：域外 dtype 或 x1/x2 不一致应返回 GRAPH_FAILED，修复前上述输入全部返回成功。

覆盖 8 行 op_issue（in-diff 3 canonical + 5 alias）：bitwise_and#IEC-F1~8b39202f、bitwise_and#board/host-execution/HOSTEXEC-F1~8b39202f（alias）、bitwise_xor#host-exec-inferdtype-relation~4ff73302、bitwise_xor#host-exec-inferdtype-domain~4ff73302（alias）、bitwise_xor#infer-exc-dtype-host-accept~4ff73302（alias）、bitwise_xor#infer-exc-dtype-mismatch~4ff73302（alias）、equal#IE-002~5a9e2594、equal#board/host-execution/HX-002~5a9e2594（alias）。行清单与提交行件 pr-p2cm1-slice4-rows-20261109.csv／pr-p2cm1-slice4-submit-rows-20261109.csv（sha8 812aeb4d）。状态为静态修复、待上板验证，不计已修。

变更摘要

本 PR 修复 bitwise_and、bitwise_xor、equal 三个算子在 Host 图推断阶段的 dtype 校验缺失问题。原实现中 BitwiseAnd/BitwiseXor 通过 InferDataTypeOutputSameAsInput 直接照抄输入 dtype，InferDataType4Equal 无条件输出 DT_BOOL，均不读取输入 dtype，导致域外 dtype 与 x1/x2 dtype 不一致的情况在推断阶段返回成功、错误推迟到执行阶段。改为自定义校验回调后，非法输入将在图推断阶段即返回 ge::GRAPH_FAILED。

主要改动

  • BitwiseAnd dtype 校验：在 bitwise_and_graph_infer.cpp 中新增 IsSupportedIntegerDtype（覆盖 int8/int16/int32/int64/uint8/uint16/uint32/uint64）与 InferDataType4BitwiseAnd，校验 x1 是否在支持域内及 x1 与 x2 是否同 dtype，通过后以 x1 的 dtype 设置输出，违规时通过 OP_LOGE_FOR_INVALID_DTYPE／OP_LOGE_FOR_INVALID_DTYPES_WITH_REASON 报错并返回失败，原直通注册行被替换。
  • BitwiseXor dtype 校验：在 bitwise_xor_graph_infer.cpp 中以同一形态新增 InferDataType4BitwiseXor，同时覆盖域外 dtype 拒绝与跨输入 dtype 一致性检查，输出 dtype 取 x1 的 dtype。
  • Equal 跨输入等值校验：在 equal_graph_infer.cpp 的 InferDataType4Equal 中保留输出为 DT_BOOL，但先比较 x1 与 x2 的 dtype，不一致时报错并返回 ge::GRAPH_FAILED。
  • 错误上报方式统一：三处均复用 OP_LOGE_FOR_INVALID_DTYPE／OP_LOGE_FOR_INVALID_DTYPES_WITH_REASON 宏输出具体 dtype 信息与原因，使推断失败原因可定位。
