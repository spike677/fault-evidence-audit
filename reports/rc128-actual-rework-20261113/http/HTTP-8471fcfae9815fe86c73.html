变更摘要

本 PR 主要针对 aclnnAllGatherMatmul 系列算子文档进行修正与统一：在 aclnnAllGatherMatmul 的错误码表中补充 x1 的 k 轴为 0 的校验失败场景，在 aclnnAllGatherMatmulV2 的 ACLNN_ERR_PARAM_INVALID（161002）错误码表中细化了参数数据类型、shape、streamMode/commMode 取值以及 format 与空指针相关描述，同时将 Atlas A2 与 Ascend 950PR&950DT 系列产品的组网表述由 "all mesh" 统一为 "Full Mesh（全互连）"，并同步更新中英文文档。

主要改动

  • aclnnAllGatherMatmul 错误码表补充: 在中文与英文文档的 ACLNN_ERR_PARAM_INVALID 错误码表中新增"x1 的 k 轴为 0"这一返回条件，明确该参数非法场景。
  • aclnnAllGatherMatmulV2 错误码描述细化: 将原单条错误描述拆分为三条，分别覆盖数据类型与 shape（维度/尺寸）越界、streamMode/commMode 取值非法、以及 format（ND/NCL、x2 为 INT4 时不支持 FRACTAL_NZ）和 x1Scale/x2Scale/amaxOut 空指针约束。
  • 组网表述统一: 将 mc2/all_gather_matmul 的 README 及 aclnnAllGatherMatmul.md 中 Atlas A2、Ascend 950PR&950DT 的 "all mesh" 统一为 "Full Mesh（全互连）"。
  • 英文文档同步: aclnnAllGatherMatmul_en.md 与 aclnnAllGatherMatmulV2_en.md 同步英文表述，将 "all mesh networking" 改为 "full mesh networking"，并对应补充错误码条目。
