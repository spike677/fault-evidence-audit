1. 概述
1.1 简介
本提案目标是将torch_npu上的随机数生成 API（Dropout、均匀分布 uniform 、指数分布 exponential ）在A5代际与 PyTorch 原生行为对齐。使 NPU 随机数 API 在语义和数值行为上与 PyTorch CPU/CUDA 实现一致，从而消除跨平台迁移的随机性差异。
1.2 动机
从模型训练的跨平台可复现性，生态兼容提升方面考虑，同Pytorch对齐随机数API具有必要性。
1.3 目标
通过底层算子和框架侧的一致性实现，使得随机数API在A5代际上同Pytorch CUDA数值对齐。
