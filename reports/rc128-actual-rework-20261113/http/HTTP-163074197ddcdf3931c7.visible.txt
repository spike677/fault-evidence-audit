描述
Broadcast 公共 tiling 路径为不使用 GM workspace 的 Vector 算子预留了冗余系统空间。本次在
BroadcastBaseTiling::DoTiling
的成功出口调用
GetWorkspaceSizes(1)
、检查返回指针并显式写入 0，替换默认系统 workspace 预留。
修改集中于一个公共头文件，一维、广播和非连续调度共用该出口；不在各算子重复覆盖 workspace，不改变 tiling key、分块计算或 kernel 数值逻辑。本 PR 不修改 CMake。
