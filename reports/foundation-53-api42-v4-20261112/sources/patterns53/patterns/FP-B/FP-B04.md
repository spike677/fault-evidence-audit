# FP-B04 aclnn 必选入参空指针校验缺失（含可选输出反向依赖）

> [← 库索引](../../README.md) ｜ [变更记录](../../CHANGELOG.md) ｜ 类别：功能/兼容 ｜ 风险：高（S2×O3=6） ｜ 状态：活跃

- **元数据**：类别 功能/兼容 ｜ 风险 高（S2×O3=6）｜ 状态 活跃 ｜ 来源 四仓 issue 检索 + 源码静态扫描（2026-09-12）；v2.18 增补子型②（现网修复复盘 26-02，2026-11-05）
- **适用**：仓 All ｜ 侧别 Host ｜ 载体 aclnn源码 ｜ 触发 必须触发 ｜ 默认启用 true
- **子型**：① **必选入参未拦截**（原主干，`nullptr` 透传下游解引用）；② **可选输出反向依赖**（output-mask 允许缺省的输出被兄弟输出路径读取 shape/view/元信息）。两型方向相反，须分别过检视清单。
- **故障机理**：aclnn 两段式接口（GetWorkspaceSize / Execute）对必选入参（输入 tensor、scalar、属性数组、属性字符串）未做 `nullptr` 拦截即向下透传，下游解引用空地址。**三类成因**：① **必选入参**未拦截——适配层由模板脚本生成导致校验宏漏插；多接口共享的公共校验函数内直接解引用（如 `strcmp`），入口仅校验了部分参数；校验位置晚于首次解引用；tiling/infershape 层 `GetData()` 返回值未判空。② **可选输出**（`outputMask` / `aclBoolArray` 门控的反向输出）——由 output-mask 允许缺省的输出指针为 `nullptr`，但某条计算路径仍按「所有输出都会请求」的假设去读它的 shape、建 view 或反推另一侧梯度（v2.18 增补，实证 26-02）。②与本卡 ①的**方向相反**：① 是「该拦没拦」，② 是「该跳没跳」。 ③ **可选输入省略后解引用（v6.33）**：资料把某输入标为 OPTIONAL，实现也在 `GetOptionalInputShape()` 返回 `nullptr` 时未判空就调 `->GetStorageShape()` / 参与偏移计算；与 ② 的区别是对象从「可选输出」换成「可选输入」。
- **触发条件**：① 任一必选入参传 `nullptr`；GetWorkspaceSize 或 Execute 阶段任一阶段；尤其易发于共享校验函数被多入口复用的算子族。② 只请求部分输出（如 backward 只算 dw 不算 dx），被省略的那一路输出为 `nullptr`，而兄弟输出路径读取了它的 shape/view。
- **典型表现**：**SIGSEGV（rc=139，必现）**；或算子侧未拦截透传给 GE/tiling 后 coredump；或返回非 161001 的错误码（如 561103）——后者易被误判为「已校验」而漏提缺陷。
- **源码审查映射点**：`GetWorkspaceSize` 入口的参数解引用点（`strcmp`/`GetDataType`/`ToFloat` 等）是否前置了 `OP_CHECK_NULL`；多入口共享的公共校验函数（如 `CheckFusedOpType`）内部是否自校验，而非依赖各入口分别校验；`CheckParams` 中 `CHECK_RET(..., ACLNN_ERR_PARAM_NULLPTR)` 是否覆盖全部必选参数；tiling/infershape 中 `GetData()` 返回值、属性字符串指针是否判空；校验顺序（是否存在「先用后校验」）。**可选输出（成因②）额外查**：每个 `outputTensor.*` 解引用点是否位于 `if ((*outputMask)[i])` 之内；是否存在「本路径只算 dw，却读 dx 的 `GetViewShape()` / 用 dx 作 `ViewWithShape` 源」这类**跨角色反向依赖**；`OpExecute` 中所有输出后处理（Cast/ViewCopy/Reshape）是否逐个被 mask 门控，而非只门控赋值处。
- **控制变量（v6.30）**：**必须固定**——只把**一个**必选入参置为 `nullptr`，其余入参全部合法且非空；每个入参单独跑一次，不合并 ｜ **允许变动**——被置空的入参 ｜ **多变量同变的典型误判**——一次把多个入参同时置空 → 只能知道「有人没判空」，不知道是哪一个，也无法定位到具体校验函数；实测首版判出 181/399 = 45% found，真机 26 次逐个注入后 26/26 都返回 161001
- **测试拦截建议**：`nullptr` 探针用例覆盖「算子 × 入参位置 × 两段式阶段」全矩阵；判读 rc=139（崩溃）/ 1（断言 FAIL）= 缺陷存在，期望返回 `161001`（`ACLNN_ERR_PARAM_NULLPTR`）；特别针对共享校验函数的算子族，须逐个入口独立置空验证（不可只测其中一个入口）；gdb 取栈定位解引用点。**可选输出（成因②）额外测**：对每个支持 output-mask 的接口跑「仅请求输出 i」的单输出组合（n 个输出至少 n 次调用，不得只测全请求基线）；backward 类接口必须有「只算 dx」「只算 dw」「全算」三档对照，并逐档验证未请求的输出不被触碰且已请求输出数值正确。
- **实证案例**：ops-nn #5531 / #5532 `aclnnFusedQuantMatmulWeightNz` 与 `aclnnFusedQuantMatmul` 共享 `CheckFusedOpType`，入口仅 `OP_CHECK_NULL(x1/x2)`，`fusedOpType=nullptr` 触发 SIGSEGV（gdb 栈 `strcmp → aclnnFusedQuantMatmulGetWorkspaceSizeCommonProcess`），期望 161001 实测 rc=139；#5372 / #5373 同根因另有两次记录（**同一根因四连发**）；#4784 fqmm x1/x2 空指针**校验过晚** Segmentation Fault；#4586 wqbmm 在空指针校验**前**通过 x1 调用函数致 coredump；#5644 `biasSizes=nullptr` 未拦截透传 GE 致 coredump（环境 **950**）；#5329 foreach 系列缺少 tensor list 空指针校验；#3383 aclnn_add_rms_norm_quant_v2 缺校验；#4555 aclnnBatchNorm 空 input + nullptr saveMean/saveInvstd 触发 core dump；#4697 GRU 传 nullptr coredump；#1293 aclnnIndexCopy 部分空指针未校验致多线程报错。另：ops-cv #912/#842/#294/#491/#295（Upsample 系列 `outputSize` 数组、GridSampler3D）、#852（NMS）、#221（IouV2 **先使用 attrs 后检验**）；ops-math #2776（`aclnn_logdet.cpp:165`）等 `【缺陷报告】空指针解引用` 批量审计 #2762–#2777、#864（exp/sqrt 缺校验 coredump）、#2501（aclnnArange 预期 161001 实测 561103）；ops-transformer #4516/#4375/#4216/#4728（grouped_matmul 系列、BSAG、FAG 的 `layout` 类属性字符串）。补充变体：ops-nn #5705（closed）convolution_forward `CheckDisContinuousStride` 校验命中后仅 `OP_LOGE` **缺 return**，防御形同虚设，后续按 `dims` 访问 vector 越界 UB——「校验写了但未生效」与「未校验」同族，审查时须核对校验命中后的控制流。**成因② 实证（v2.18 增补，来源现网修复复盘 26-02）**：ops-nn PR #1001 `aclnnConvolutionBackward`——只求 dw 时 dx 输出为 `nullptr`，dw 专用路径却读取 `gradInput` 的 shape 并用它创建视图，触发 **core dump**；修复改为完全使用 `gradWeight`，并把各输出后处理收进 `(*outputMask)[i]` 门控。修复后形态锚点：`conv/convolution_backward/op_api/aclnn_convolution_backward.cpp:911-935`（`OutputViewProcess` 内 gradInput/gradWeight/gradBias 逐个 `if ((*outputMask)[i])` 包裹，@ops-nn HEAD b27fda2）。**判据要点**：本案不是「忘记判空」，而是「按错误所有权假设读取了另一路输出的元信息」——所以 `CheckNotNull` 覆盖再全也拦不住。 **2026-11 批次（v6.33 反哺）**：本簇 25 条；代表 ops-transformer#6539（可选输入/输出省略 SIGSEGV）、ops-nn#7095（AdaLayerNormBackward weightOptional/biasOptional 空指针）、ops-transformer#6651（attenMask nullptr SIGSEGV）。
