变更摘要

本 PR 修复 matmul/gemm_v3 的 tiling key 生成逻辑：在 GemmV3TilingKey::GetTilingKey() 中，模板参数 out_ 不再参与 tiling key 编码，而是固定使用 MatMulV3L0C2Out::ON_THE_FLY。其目的是避免 tiling key 落入 kernel 侧不存在的 fixpipe 模板组合（gemm_v3 的 L0C2OUT_MODEL 仅 ON_THE_FLY 有合法组合），从而保证 host 侧生成的 tiling key 与 kernel 侧实际存在的模板保持一致。

主要改动

  • 固定 L0C2OUT 参数取值：GET_TPL_TILING_KEY 的最后一个入参由 static_cast<uint64_t>(out_) 改为 static_cast<uint64_t>(MatMulV3L0C2Out::ON_THE_FLY)，使 out_ 成员不再影响 tiling key。
  • 避免非法模板组合：tiling key 固定编码为 ON_THE_FLY 后，不会再生成 kernel 侧不存在的 fixpipe 模板组合，保证 gemm_v3 的 L0C2OUT_MODEL 只有合法分支被选中。
  • 改动范围集中：仅涉及 gemmv3_tiling_key.cpp 中 GetTilingKey() 的一行表达式调整，其余 tiling key 维度（apiLevel_、atrans_、btrans_、batchModel_、model_、fullLoad_）的编码方式保持不变。
