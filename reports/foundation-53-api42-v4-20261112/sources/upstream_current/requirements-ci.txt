# CI / 本地门禁的第三方依赖清单
#
# 为什么单独一份：scripts/ci_gate.py 把 `scripts/scan_dataflow.py --self-test` 列为
# **blocking**，而该自检开头就 `from tree_sitter import Language, Parser` +
# `import tree_sitter_cpp`（scan_dataflow.py 的 `_parser()` / `self_test()`，无缺包分支）。
# 这两个包不在标准库里；CI 镜像 `python:3.11-slim` 不自带，.gitlab-ci.yml 此前也没装，
# 于是「按仓库自己公布的 CI 定义跑」时阻塞项必红（22/23，退出码 1）。
#
# 安装（CI 的 before_script 与本地同一份）：
#   python -m pip install --no-cache-dir -r requirements-ci.txt
#
# 版本固定的理由：数据流工具用 `Parser(Language(tree_sitter_cpp.language()))` 这套 API，
# 跟着上游大版本漂会静默改变解析行为；固定到实测组合才有可重复的判定。
# 实测组合（CPython 3.12.10 / Windows）：tree-sitter 0.26.0、tree-sitter-cpp 0.23.4。
# 已确认这两个版本在 CPython 3.11 + manylinux x86_64 有预编译 wheel（python:3.11-slim 可用）。
tree-sitter==0.26.0
tree-sitter-cpp==0.23.4
