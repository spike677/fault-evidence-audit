Steps to reproduce the issue / 重现步骤 (Mandatory / 必填)
可在定向 UT/stub 中复现，无需设备：
构造注册为 InsAllGatherSequenceNHRNHRMesh1D 的三层 executor。
让任一 level 模板的 GetRes() 返回 HCCL_E_INTERNAL。
调用 PrepareResForTemplate() 或其上层 Orchestrate()。
当前代码忽略错误，继续读取对应 AlgResourceRequest。
令 threads_ 长度小于任一 slaveThreadNum + 1；当前 assign 的第二个迭代器越过 end()，构成未定义行为。
Describe the expected behavior / 预期结果 (Mandatory / 必填)
三次 GetRes() 均用 CHK_RET 或等效方式传播首错。
每次 threads_ 切分前验证请求数不超过 threads_.size()；失败返回 HCCL_E_PARA。
资源准备失败后不得写入 levels_ 或进入 GenTempResource/KernelRun。
增加三组 GetRes 失败注入、三组线程不足和一组全成功路径 UT。
Related log / screenshot / 日志 / 截图 (Mandatory / 必填)
确定性控制流：
level 模板 GetRes 失败
→ 返回值丢弃
→ slaveThreadNum 未保证有效
→ begin() + slaveThreadNum + 1
→ 可能越过 threads_.end()
→ 资源错误丢失或后续模板异常
当前无硬件日志；结论来自固定基线源码。
