描述
TransData 的 RT2 Elewise InferShape 不等价于 RT1：跨 origin format 时把构图方预置目标改为输入 shape；改为空回调同样不能保留目标。仅按属性补正向公式也无法完整承接旧图中必要的目标约束。
删除
conversion/trans_data/op_host/trans_data_infershape.cpp
及只绑定该 shape 注册的 6 个 UT，保留
op_graph/trans_data_graph_infer.cpp
的独立 InferDataType。
关联的Issue
关联 #4650；
测试
从删除后保留的生产 dtype 源码编译并用真实
OpImplSpaceRegistryV2
加载，确认 TransData
infer_shape=null
、
infer_datatype
保留。
两份完整 proto 的修改前后四个源文件均通过真实 CANN/GE 头语法编译；回调使用 -O2 -Wall -Wextra -Werror -ftrapv 严格编译。
六组实际回调注册/契约测试各 4704 个描述组合、9408 次重复调用通过，并含两种目标的歧义反例；注册负向控制有效。该矩阵验证回调语义，不代表全部组合为合法设备格式。
910B3 / CANN 9.2.0：主 proto 与 AICPU proto 的等价原始 GE Session 用例各 3 次通过；输入 [32,32,1,1] INT8、groups=2，输出 [2,1,16,32]、1024 字节、1024 个值正确，确认 GE V1 与 AICPU kernel 路由。
ops-math 原生
bash build.sh -u --opkernel_aicpu --ops=trans_data --soc=ascend910b
：22/22 通过，另有 1 个存量禁用用例。
同进程 ABBA/BAAB 最终 A/A、A/B 各 120 张图、3720 次 RunGraph，每路径 1800 个稳态样本；speedup=old/new 的 bootstrap95 区间 A/A [0.9778,1.0026]、A/B [0.9755,1.0197]，通过 >=0.97 门槛。结论限给定用例的 host RunGraph。
