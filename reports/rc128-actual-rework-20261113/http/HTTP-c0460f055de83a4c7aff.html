描述

SubMulConcat 是内部融合算子（无公开 ACLNN/E2E 接口）。本次修复 InferShape 的三类校验缺口，并同步最小文档与 UT：

  • 动态末维 -1：原样传播，不再执行 4*W；非负末维继续计算并保留正向溢出检查。
  • 负描述符边界：-1 合法；-2（UNKNOWN_DIM_NUM，未知 rank）及 <-2 拒绝。
  • axis：仅接受 -1/2；缺失按注册默认 -1，其他值返回 GRAPH_FAILED。
  • x/y 一致性：y 必须 rank 3；x/y 对应已知维必须相等；合法未知维跳过静态不等判断；Tiling 原检查保留。
  • README/README_en：明确 axis、动态维 -1、未知 rank -2 语义，并补充内部 Host 定义链接。
