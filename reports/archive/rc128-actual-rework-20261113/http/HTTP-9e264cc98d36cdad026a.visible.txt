1. aclnnAllGatherMatmul 错误码表补齐“x1的k轴为0”场景（161002），与
   op_api CheckNotEmptyTensor 校验返回路径一致，rowspan 与描述行数对齐。
2. aclnnAllGatherMatmulV2 错误码表精简补齐 161002 触发条件：数据类型与
   shape（维度/尺寸）、streamMode/commMode 取值、format 约束（含 INT4 x2
   不支持 FRACTAL_NZ）及量化/fp16/bf16 场景的 scale、amaxOut 空指针约束，
   rowspan 与描述行数对齐。
3. quantScale 维持“当前仅支持传入空指针场景”：op_api 层虽允许非空 fp8
   scalar 通过入口校验，但 tiling 层（AllGatherMatmulTilingBase::
   CheckParaInvaild）对非空 quantScale 一律拒绝，端到端不支持，文档口径
   以端到端为准，无需修改。
4. all_gather_matmul 文档与 README 统一组网术语：“all mesh组网”改为
   “Full Mesh（全互连）组网”（英文为 full mesh networking），与代码侧
   full_mesh 实现命名一致。
